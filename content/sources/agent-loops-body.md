Every agent eventually does it: the same failing command three times in a row, the endless "let me look at one more file," the confident "done!" on a task that isn't. The frustrating part is that agent loops almost always have the same handful of causes — and the fixes are usually one line.

This cheat sheet is the reference I wish I'd had: every common loop as a symptom → cause → fix row, so you can diagnose from the behavior you're seeing instead of guessing.

## What's inside

- **The symptom → cause → fix table** — seven loop patterns, from "repeats the same failing action" to "declares success on an unfinished task," each with the one-line remedy
- **Five golden rules** for loop-proofing any agent: errors louder than successes, one change per step, visible attempt logs, observable definitions of done, and exits on every loop
- **A three-step triage** for when an agent is stuck right now and you need it moving again in five minutes

## Who it's for

Anyone running coding agents, automation loops, or tool-using LLMs — whether you built the agent or just operate one. If you've ever watched a terminal scroll the same error for ten minutes, this page is for you.
